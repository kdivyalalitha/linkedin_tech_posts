# Oracle DBA

Welcome to the **Oracle DBA** section of my GitHub portfolio.

This repository contains practical Oracle Database Administration concepts, production support scenarios, and database best practices. The articles focus on core Oracle Database technologies, backup and recovery, performance, and administration fundamentals.

## 📚 Topics Covered

- Database Startup & Shutdown
- PFILE vs SPFILE
- Control Files, Data Files & Redo Log Files
- ARCHIVELOG & NOARCHIVELOG Mode
- RMAN Backup & Recovery
- Database Cloning
- Performance Monitoring
- Oracle Networking (Listener, TNS & SQL*Net)

**Goal:** To build a practical Oracle DBA knowledge base for learning and real-world database administration.
